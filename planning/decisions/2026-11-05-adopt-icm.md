# ADR: Adopt the ICM Architecture and Skills Routing

- **Date:** 2026-11-05
- **Status:** Accepted

## Context

The Travel Planner has working code, but its agent-facing organization was partial: a single
`GEMINI.md` map, four-section `CONTEXT.md` files, no installed skills, no routing authority, no
pipeline, and no checkpoint discipline. The `icm-core` blueprint defines a consistent structure for
every repository: a Layer 1 map, Layer 2 room contracts, a tracked skill suite with an intent router,
and a 9-step engineering pipeline.

## Decision

Adopt the ICM architecture in full:

1. `AGENTS.md` is the single Layer 1 authority; `CLAUDE.md` and `GEMINI.md` are pointers only.
2. Every workspace (`src`, `ops`, `data`, `planning`, `docs`, `tests`) has a 6-part `CONTEXT.md`.
3. `.agents/skills/` is the tracked skill source of truth; `.claude/skills` is a junction.
4. `skills-orchestrator` and `skills-route` are mandatory at session start; the 7 categories are
   customized for travel/price work.
5. `CODE_PIPELINE.md` is the mandatory 9-step workflow.
6. The database is append-only under `data/`; tests live at root `tests/`; task logs live in
   `planning/tasks/`.

## Consequences

- The repository has one authority per concern; `GEMINI.md` no longer duplicates routing.
- Agents must declare `[Intent | Skill Stack | Env]` before acting.
- The skill suite adds ~41 directories to the repo; this is intentional and tracked.
- The database and `.env` stay out of git; the `.claude/skills` junction is recreated after cloning.
- Structural drift is caught by `tests/test_icm_structure.py`.

## Alternatives considered

- **Keep the partial `GEMINI.md` map.** Rejected: duplicate authorities drift and the skill suite has
  no routing authority.
- **Install only the skills used today.** Rejected: the blueprint's value is the full portfolio
  (debugging, review, research, checkpoint); pruning would break category coverage.
- **Leave tests in `src/tests/`.** Rejected: the blueprint keeps tests at the repo root so `/src`
  remains pure engines.
